# 🎬 فيديو تعريفي لبرنامج الإعلام الرقمي
## كلية الإعلام والاتصال – جامعة الإسكندرية الأهلية (ANU)

مشروع إنتاج فيديو سينمائي وثائقي (Documentary Storytelling) لتعريف طلاب الثانوي العامة وأولياء أمورهم ببرنامج الإعلام الرقمي، من الفكرة الإبداعية لحد التسليم النهائي.

---

## ⚠️ ملاحظة شفافية مهمة (اقرأها قبل أي شيء)

كل الحقائق المستخدمة عن الجامعة والبرنامج في هذا المستودع مبنية على مصادر تم التحقق منها:

1. **الموقع الرسمي** [anu.edu.eg](https://anu.edu.eg) — الرؤية، الرسالة، الأهداف الاستراتيجية.
2. **صفحة الفيسبوك الرسمية** لبرنامج الإعلام الرقمي (Digital Media Program - Alexandria National University) — التعريف الرسمي للبرنامج.
3. **خبر صحفي حقيقي وموثّق** تصدّر جريدة الأهرام وصدى البلد والأسبوع، عن حملة توعوية رقمية نفذها طلاب الفرقة الثالثة ببرنامج الإعلام الرقمي، ضمن مقرر "إدارة المنصات الرقمية" (الجانب النظري: د. إسراء سعيد، الجانب العملي: الأستاذ زياد عمرو).
4. **ويكيبيديا** (نسخة إنجليزية) — حقائق عامة عن تأسيس الجامعة وموقعها وعدد كلياتها.

أي تفصيلة **غير موثقة رسميًا** (مثل أسماء تخصصات فرعية دقيقة، مناهج مفصلة، أو أرقام توظيف) معلَّمة بوضوح في كل ملف بعلامة:

> **[افتراض قابل للتعديل من الكلية]**

**قبل التنفيذ الفعلي، لازم الكلية/فريق العمل يراجعوا كل النقاط المعلّمة بهذه العلامة ويؤكدوها أو يعدّلوها بالمعلومة الرسمية الصحيحة.** راجع تفاصيل المصادر كاملة في [`research-notes.md`](./research-notes.md).

3. افتح Pull Request مع وصف واضح للتعديل.
